# LocationScout — Feature Rollout Guide

## Текущее состояние: BETA (2 экрана)

Активные экраны: **References → Setups**.
Скрытые: Input (авто-фикстура), Research, Analysis (Bible review), Light/States (Mood states), Outputs.

Ничего не удалено — всё закомментировано или скрыто за allow-list / условным рендером. Возврат — построчные правки ниже.

## Файлы

- `.env.beta` — backend allow-list (`ENABLED_TOOLS=...`).
- `src/ui/.env.beta` — UI feature-flags (`VITE_FEATURE_RESEARCH=false`, etc.).
  - Vite загружает `.env.beta` только при запуске с `--mode beta`. Если запускается обычным `npm run dev:ui`, флаги не читаются (но они на сегодня и не используются — это маркеры будущего поведения).

## Граничные правила

- 14-hex палитра: новых hex-литералов нет; `#A6F77E`, `#111111`, `#F7927E` в SetupsPage баннере — все из разрешённого списка.
- Никакие файлы не удалены (страницы Research/Analysis/LightStates/Outputs остаются на диске).
